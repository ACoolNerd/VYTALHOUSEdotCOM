# VYTAL HOUSE — DESIGN SYSTEM SPECIFICATION

## Aesthetic Philosophy
Cinematic, architectural, dark mode first. Combines Remedy Place social lounge warmth with Reecess high-contrast luxury aesthetics.

## Color Tokens
- **Background Obsidian**: `#0B0F17` / `#080B11`
- **Brushed Gold Accents**: `#C5A059` / `#E6C687` (Hex gradient)
- **Clinical Blue (PC Entity)**: `#0EA5E9` / `#38BDF8`
- **Wellness Gold (MSO Entity)**: `#F59E0B` / `#D97706`
- **Success Emerald**: `#10B981`
- **Signature Orange Hover**: `#F97316` (Used on footer credits `"ACoolWEBSITE Made with 🧡 by ACoolNERD"`)

## Typography
- **Headings**: `Space Grotesk`, ALL-CAPS font-bold
- **Body**: `Inter`, clean sans-serif
- **Data / Metrics**: `Space Mono` / `font-mono`
