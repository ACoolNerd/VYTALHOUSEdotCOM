# VYTAL House Brand Integration — Website

**Official brand version:** 1.0.0  
**Canonical source:** `ACoolNerd/VYTALHouse/brand-system`  
**Official positioning line:** **Renew • Restore • Recharge**

This repository is the production website implementation for VYTAL House.

## Required website implementation
- Use approved master assets and preserve logo aspect ratio and clear space.
- Use the full wordmark in primary navigation or hero contexts and the monogram for favicon/app/profile contexts.
- Replace active instances of **Recovery • Contouring • Longevity** with **Renew • Restore • Recharge**.
- Map theme colors and typography to the synchronized token files in this directory.
- Add approved favicon, web manifest icons, Open Graph image, structured metadata, and meaningful logo alternative text.
- Validate mobile, tablet, desktop, accessible contrast, and social-sharing previews before release.
- Keep legal, medical, clinical, financial, zoning, and investment claims appropriately reviewed and disclosed.

Do not create a competing logo, tagline, palette, or app icon. Record the brand-system version in release notes.
