# VYTALHOUSEdotCOM — VYTAL ARC Signature Glow

Production website implementation for the VYTAL House VYTAL ONE / VYTAL ARC smart hydration platform.

## Official identity

- Brand system: VYTAL House v1.0
- Official positioning line: **Renew • Restore • Recharge**
- Canonical assets and governance: `ACoolNerd/VYTALHouse/brand-system`
- The legacy line `Recovery • Contouring • Longevity` is deprecated for new production.

## Website scope

The deployed site includes:

- VYTAL ARC Signature Glow product architecture
- V-Core Smart Cap, V-Pods, Glow Base, Glow Dock, ARC Magazine and VYTAL OS
- Fixed-serving daily routine and direct user-confirmation guardrails
- DTC memberships and replenishment architecture
- Corporate, government/contractor, technology, healthcare, athletics and hospitality channels
- P0–PVT engineering roadmap, compliance, IP and first-90-day actions
- NotebookLM, audio, video and short-form production architecture
- Responsive interest form with local preview storage and CSV export

## Deployment

GitHub Actions publishes the repository root to GitHub Pages after changes reach `main`.

Custom-domain DNS and the GitHub Pages custom-domain setting for `vytalhouse.com` must be verified separately.
